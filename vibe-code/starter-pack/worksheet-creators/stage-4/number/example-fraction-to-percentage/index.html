Fraction to Percentage

Prints the same double number line the class was taught with. PLACEHOLDER: your instructions here.

The sheet code reproduces an identical sheet — type last term's code to reprint exactly the same questions. Versions give the same questions in a different order. With the number line showing, a page holds 8 questions; without it, 18.

Teacher check — preview 20 and verify the level

Twenty questions from the current settings, with answers. Mark them by hand and look for: answers of the wrong kind for the level you picked, denominators too big to draw, and repeats. The line underneath re-derives every answer a second way and counts how many are the kind the level promised.
