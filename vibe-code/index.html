What to do with it

  1. Open itDouble-click the file. It works right now — change the step to 0.25, then to −3, before you change anything else.
  2. Decide one thingNot a maths website. One lesson, one class, one thing that is hard. Then write the sentence that tells you it worked.
  3. Hand it overDrag the file into a new chat and use the prompt below. Then check the maths by hand — three of them, properly.

The prompt

[Context] This is my starter file. Read the brief in the comment at the top and follow those rules.

[The change] Change it from number line jumps to [YOUR THING].

[The test] It works when I can [ONE SENTENCE — how you would check it].

[The limits] Keep it one self-contained file, no libraries, keep the :root design tokens, and don't add anything I didn't ask for. Give me back the whole file.

Four parts: context, the change, the test, the limits. Leave one out and you spend the next twenty minutes correcting.
